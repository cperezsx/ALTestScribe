# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through a GitHub security advisory or by contacting the repository owner. Do not disclose a suspected vulnerability in a public issue before it has been assessed.

## Data handling scope

AL TestScribe does not collect telemetry or send report contents to a remote service. It writes report files into the opened workspace, where they remain under the user's control.

Exported reports can contain business names, test values, object names, and error details. Treat those files as potentially sensitive. Do not commit or share them unless your project's security policy permits it.
