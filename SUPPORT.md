# Support

Open a bug report at:

https://github.com/cperezsx/ALTestScribe/issues

Include the following when it is safe to do so:

- AL TestScribe version.
- Visual Studio Code version and operating system.
- AL Language extension version.
- Whether export mode is `automatic` or `manual`.
- The configured report formats and output directory.
- Relevant lines from the **AL TestScribe** output channel, with private data redacted.

Do not include credentials, connection strings, customer names, proprietary test data, or complete unredacted error reports in a public issue.
